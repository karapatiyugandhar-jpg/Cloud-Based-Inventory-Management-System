# Cloud-Based Inventory Management System

## Included features
- Dashboard with inventory KPIs
- Product add, edit, delete and search
- SKU, category, supplier, price and stock tracking
- Low-stock alerts
- Stock In / Stock Out
- Automatic stock calculation
- Supplier management
- Reports by category
- Responsive desktop/mobile UI
- Browser localStorage persistence
- Demo data and reset option

## Run
Extract the ZIP and open `index.html` in Chrome, Edge or Firefox.

## Cloud deployment
This is a frontend cloud-ready project. It can be deployed to Firebase Hosting, Netlify, Vercel or GitHub Pages. For a true multi-user cloud system, replace localStorage in `app.js` with Firebase Firestore, Supabase, MySQL/API or another cloud backend.
